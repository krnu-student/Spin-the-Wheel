# Колесо натхнення

Односторінковий сайт: крутиш колесо — отримуєш запитання, з якого можна почати заняття.
Працює на телефоні та комп’ютері, без бібліотек і збирання проєкту.

## Що в папці

| Файл | Призначення |
|---|---|
| `index.html` | уся сторінка (розмітка, стилі, скрипт, запитання) |
| `favicon.ico`, `assets/` | іконки сайту (вкладка браузера, екран «Додому» на телефоні) |
| `site.webmanifest` | дані для додавання сайту на головний екран телефона |
| `.nojekyll` | вимикає обробку Jekyll на GitHub Pages |

## Як викласти на GitHub Pages

1. Створіть репозиторій на github.com (або відкрийте наявний).
2. Натисніть **Add file → Upload files** і перетягніть **вміст** цієї папки (разом із папкою `assets` і прихованим файлом `.nojekyll`, якщо він видимий). `index.html` має лежати в корені репозиторію.
3. Натисніть **Commit changes**.
4. Відкрийте **Settings → Pages**. У розділі **Build and deployment** оберіть **Deploy from a branch**, гілку `main` і папку `/ (root)`, потім **Save**.
5. Через 1–2 хвилини сайт з’явиться за адресою `https://<ваш-логін>.github.io/<назва-репозиторію>/`.

## Як змінити запитання

Відкрийте `index.html` і знайдіть масив `GROUPS` у блоці `<script>`. Кожна група має назву (з емодзі на початку, воно показується на колесі на телефоні) і список запитань. Колесо саме підлаштується під кількість запитань.

## Як змінити кольори

Кольори сторінки лежать на початку `index.html` у блоці `:root` (змінні `--sky-top`, `--g1`, `--btn` тощо). Кольори секторів колеса — масив `COLORS` у скрипті.
